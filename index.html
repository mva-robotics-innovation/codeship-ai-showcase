02 / AI planning

Shape the project with Bedrock

The Lambda handler can call Amazon Bedrock to return a stack, concise description, tasks, and a suggested file plan. AWS credentials and model access are required.

Try the voice-command flow

After the Alexa skill is configured and enabled for testing, say:

→“Alexa, open Code Ship.”
→“Build hostel management system.”
→“Deploy it.”

Voice commands work through the configured Alexa skill, not by clicking this webpage. The deployment action must be connected to real GitHub/Vercel APIs before it can create live links.
