# CodeShip Alexa+ demo script (2–3 minutes)

1. **Problem (20 sec):** Turning an app idea into a structured implementation plan takes time.
2. **Voice workflow (45 sec):** In Alexa Developer Console Test simulator, say “open code ship,” then “build hostel management system.”
3. **Planning (40 sec):** Show the response card with suggested stack, tasks, and file paths. If Bedrock is configured, mention that the plan came from Bedrock; otherwise explicitly call it the demo fallback.
4. **Dashboard (25 sec):** Open `frontend-dashboard/index.html` to explain the Alexa → Lambda → Bedrock flow.
5. **Deployment roadmap (20 sec):** Say “deploy it.” Explain that real GitHub/Vercel publishing is a next integration and is not falsely simulated.
6. **Showcase (20 sec):** Open the landing page and Robotics Academy demo.
