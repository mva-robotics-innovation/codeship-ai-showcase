# CodeShip AI Showcase + Robotics Academy

This repository contains the public landing page and a static Robotics Academy demo.

## Local preview
Open `index.html` in a browser. To open the generated app, open `robotics-academy/index.html`.

## Deploy to Vercel
Import this repository into Vercel and use the project root as the Root Directory. Framework preset: Other. Build command: leave empty. Output directory: `.` (or leave the default if Vercel detects static HTML). The landing page will be at `/` and Robotics Academy at `/robotics-academy/`.

## Links
- CodeShip platform: https://codeship-ai-platform.onrender.com
- Source repository: https://github.com/mva-robotics-innovation/codeship-ai-platform

## Demo limitations
Robotics Academy is a front-end demo. It stores demo edits in the current browser using localStorage and does not use a shared database or live AI integration.
